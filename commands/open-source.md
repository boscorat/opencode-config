# Open Source Expert Command

Use this command to get strategic advice on your open-source projects.

## Examples

**Project health check:**
```
/open-source health check bank_statement_parser
```

**Growth strategy:**
```
/open-source growth strategy openstan
```

**Launch planning:**
```
/open-source launch planning openstan --phase beta
```

**Monetisation options:**
```
/open-source monetisation bank_statement_parser
```

**Burnout prevention:**
```
/open-source burnout audit bank_statement_parser
```

**Debate a decision:**
```
/open-source debate "Should we add GitHub Sponsors now?" --auto-invoke
```

## Available Projects

- `bank_statement_parser` - UK bank statement extraction library
- `openstan` - Desktop UI for statement parsing + tax reporting
- `bank-statement-anonymiser` - PDF anonymisation utility
- `opencode-config` - Global OpenCode config distribution

## Available Workflows

- **health-check** - Quarterly project assessment + burnout risk scoring
- **growth-strategy** - 3–6 month roadmap planning
- **launch-planning** - Go-to-market strategy (Seed/Alpha/Beta/GA)
- **monetisation** - Revenue options (Sponsors, Open Collective, consultancy)
- **burnout-audit** - Preventive guardrails assessment
- **debate** - Invoke Confidence/Paranoia for strategic decisions

## More Info

All workflows include specific, actionable recommendations backed by evidence from successful open-source projects (ripgrep, direnv, pueue, just, fd, bat, etc.) and lessons from burnout case studies (Log4j, NumPy, Babel, event-stream).
