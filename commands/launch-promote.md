# Launch Promoter Command

Use this command to get marketing and promotion guidance for your open-source projects.

## Usage

```
/launch-promote <platform> <project>
/launch-promote launch-plan <project>
/launch-promote communication-channels <project>
```

## Examples

**LinkedIn strategy:**
```
/launch-promote linkedin bank_statement_parser
```

**Full launch plan:**
```
/launch-promote launch-plan openstan
```

**Reddit strategy:**
```
/launch-promote reddit bank_statement_anonymiser
```

**Communication channels:**
```
/launch-promote communication-channels bank_statement_parser
```

**Bluesky strategy:**
```
/launch-promote bluesky openstan
```

**All platforms overview:**
```
/launch-promote overview bank_statement_anonymiser
```

## Available Projects

- `bank_statement_anonymiser` - PDF anonymisation utility
- `bank_statement_parser` - UK bank statement extraction library
- `openstan` - Desktop UI for statement parsing + tax reporting

## Platforms

- `github` - GitHub optimisation and release strategy
- `linkedin` - LinkedIn content and networking
- `reddit` - Reddit community engagement
- `bluesky` - Bluesky threads and engagement
- `mastodon` - Mastodon/Fediverse strategy
- `devto` - Dev.to articles and tutorials
- `hackernews` - Hacker News Show HN
- `friendica` - Friendica for non-technical audiences
- `stoat` - Stoat (Discord alternative) for community support

## Special Commands

- `launch-plan` - Complete launch plan across all platforms
- `communication-channels` - Recommend support channels
- `overview` - Platform-by-platform strategy summary
- `content-calendar` - Weekly posting schedule
- `templates` - Content templates for specific platforms

## Tips

- Specify the project name to get tailored advice
- The agent will read the project's README to understand its value proposition
- Ask for draft content that you can modify before posting
- Request evidence-based recommendations from successful launches
